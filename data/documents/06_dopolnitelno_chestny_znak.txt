ДОПОЛНИТЕЛЬНО: ЧЕСТНЫЙ ЗНАК — НАЗНАЧЕНИЕ, АРХИТЕКТУРА, ИНТЕГРАЦИЯ
Дата сбора информации: 01.10.2026

====================================================================
1. НАЗНАЧЕНИЕ И ПРИНЦИПЫ РАБОТЫ
====================================================================

«Честный знак» — национальная система цифровой маркировки и прослеживания
товаров. Основная задача (по crpt.ru) — гарантировать подлинность и
заявленное качество продукции для всех участников оборота.

Принципы работы:
1. Каждой единице товара (или упаковке) присваивается уникальный код
   маркировки Data Matrix.
2. Код наносится на товар/этикетку производителем или импортёром.
3. Все операции с кодом (ввод в оборот, отгрузка, приёмка, продажа,
   вывод из оборота) фиксируются в ГИС МТ.
4. Потребитель или контролёр может проверить подлинность товара через
   мобильное приложение «Честный знак».

Цели системы: борьба с контрафактом, контроль качества и сроков годности,
прослеживаемость товарных потоков, обеление рынка.

====================================================================
2. АРХИТЕКТУРА И КОМПОНЕНТЫ
====================================================================

Ключевые компоненты экосистемы:

1. ГИС МТ — государственная информационная система мониторинга за оборотом
   товаров (центральное хранилище сведений о кодах и операциях).
2. Личный кабинет участника оборота (markirovka.crpt.ru) — веб-интерфейс
   для регистрации, заказа кодов, просмотра статистики, документов.
3. Станция управления заказами (СУЗ) — инструмент заказа и управления
   кодами маркировки (для производителей/импортёров).
4. Локальный модуль Честного знака (ЛМ ЧЗ) — локальный компонент для
   обмена и офлайн-проверки кодов.
5. ТС ПИоТ (например, ЕСМ) — обязательный модуль проверки кодов на кассе.
6. API ГИС МТ — программный интерфейс для интеграции учётных систем.
7. Национальный каталог товаров — справочник карточек товаров.
8. Приложения проверки кодов — для потребителей и контролирующих органов.

Взаимодействие учётной системы (1С и др.) с ГИС МТ строится через API и/или
ЛМ ЧЗ, а проверка кодов на кассе — через ТС ПИоТ.

====================================================================
3. ТОВАРНЫЕ ГРУППЫ
====================================================================

По Википедии, «Честный знак» охватывает: товары лёгкой промышленности,
шубы (мех), обувь, табак, лекарства, молочную продукцию, шины и ряд других
групп; с 2024 года — все товарные группы.

По новостям ЦРПТ на 2026 год вводятся/действуют также: мясная продукция
(с 01.08.2026), санитарно-гигиенические товары (с 01.09.2026), средства
личной гигиены (с 01.10.2026), удобрения (с 01.11.2026), корма для
животных (обсуждается партионный учёт).

====================================================================
4. ИНТЕГРАЦИЯ С КОНФИГУРАЦИЯМИ 1С
====================================================================

Обобщение практики (названия функций зависят от конфигурации и релиза):

1С:Розница
- Розничные продажи маркированных товаров, РМК, печать этикеток,
  разрешительный режим, работа с ТС ПИоТ/ЛМ ЧЗ.

1С:Управление торговлей (УТ 11)
- Оптовый и розничный оборот, ЭДО/УПД, агрегация кодов, работа с
  транспортными упаковками, обмен с ГИС МТ.

1С:ERP (ERP 2)
- Производственная маркировка, поэкземплярный учёт, склады, интеграция
  с Меркурием/ЕГАИС и ГИС МТ.

1С:Управление нашей фирмой (УНФ)
- Упрощённая маркировка для малого бизнеса, розница, продажи.

1С:Бухгалтерия (БП 3.0)
- Учёт маркированных товаров, УПД/ЭДО, отражение операций, обмен с ГИС МТ.

Общая логика настройки: включение функциональности «Маркировка», настройка
подключения к ГИС МТ (адрес, УКЭП), настройка обменов и регламентных
заданий, настройка оборудования (ПИОТ), настройка разрешительного режима.

====================================================================
5. ОБМЕН ДОКУМЕНТАМИ, ЭДО, ГИС МТ
====================================================================

Для передачи сведений о движении маркированного товара между контрагентами
используется ЭДО и универсальный передаточный документ (УПД). Ключевые
моменты (по сообществу markirovka.ru):

- «ЭДО Лайт» — бесплатный сервис электронного документооборота от
  «Честного знака»;
- для молочной продукции, упакованной воды, БАД и антисептиков действуют
  отдельные правила передачи сведений;
- типовые ошибки обработки документов ЭДО разбираются в сообществе.

Общая схема: поставщик формирует УПД с кодами маркировки → передаёт через
ЭДО → ГИС МТ фиксирует переход права собственности → покупатель подтверждает
приёмку. В 1С это настраивается через сервис ЭДО и обмены с ГИС МТ.

====================================================================
6. ТИПОВЫЕ ОШИБКИ И РЕШЕНИЯ (обобщение)
====================================================================

1. Код маркировки не распознаётся сканером.
   Решение: проверить сканер (2D), чистоту этикетки, настройку префиксов.

2. Товар не найден в ГИС МТ при эмиссии/вводе.
   Решение: проверить карточку товара, ТН ВЭД, атрибуты, сопоставление.

3. УПД отклонён ГИС МТ.
   Решение: сверить коды, количество, статусы, реквизиты контрагента.

4. Касса блокирует продажу.
   Решение: проверить статус кода (в обороте/выведен/заблокирован),
   срок годности, настройки разрешительного режима.

5. Расхождения остатков.
   Решение: выполнить сверку с ГИС МТ, перечитать статусы, устранить
   пропущенные операции.

====================================================================
7. РОЛИ, ДОСТУПЫ, БЕЗОПАСНОСТЬ
====================================================================

Обобщение практики (зависит от конфигурации 1С и правил ГИС МТ):

- В ГИС МТ у участника оборота есть учётная запись и роли, определяющие
  доступ к операциям (заказ кодов, просмотр статистики, работа с ЭДО).
- Для обмена используется квалифицированная электронная подпись (УКЭП).
- В 1С доступ к маркировке настраивается через роли/профили: администратор
  маркировки, оператор, кассир.
- Ключи доступа (X-API-KEY — до 01.10.2026) и регистрация ТС ПИоТ должны
  храниться в защищённом виде; не передаваться третьим лицам.

Рекомендации по безопасности:
- регулярно обновлять ЛМ ЧЗ, ТС ПИоТ, прошивки ККТ;
- следить за сроками действия УКЭП;
- вести журнал обмена и проверять статусы обработки документов;
- делать резервные копии локальных баз ЛМ ЧЗ.

====================================================================
8. ПРАКТИЧЕСКИЕ РЕКОМЕНДАЦИИ ПО ВНЕДРЕНИЮ
====================================================================

1. Начать с аудита: какие товарные группы продаются, попадают ли под
   обязательную маркировку, есть ли исключения.
2. Проверить кассовый парк на совместимость с ТС ПИоТ и поддержку
   Data Matrix.
3. Зарегистрироваться в ГИС МТ, получить УКЭП, настроить личный кабинет.
4. В 1С включить маркировку, настроить подключение и обмены.
5. Установить ЛМ ЧЗ для офлайн-проверки и держать его актуальным.
6. Подключить ТС ПИоТ (ЕСМ) на каждую кассу.
7. Провести обучение персонала (кассиры, товароведы, бухгалтерия).
8. Проверить сценарии: продажа, возврат, отгрузка/приёмка, ЭДО, сбой связи.
